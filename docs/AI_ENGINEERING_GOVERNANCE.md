# AI 研发治理规范

## 1. 治理目标

AI 研发治理用于保障 AI 参与研发时的质量、安全、效率和可追溯性，形成从需求到上线的闭环管理能力。

治理目标包括：

- 建立 AI 辅助研发闭环。
- 建立 Prompt 治理体系。
- 建立 AI 代码评测体系。
- 建立 AI Review 体系。
- 建立 AI 研发工作流。
- 建立企业级 AI 研发规范。

## 2. 治理对象

治理对象包括：

- Prompt 资产。
- AI 生成代码。
- AI Review 结果。
- AI 评测用例和评测报告。
- AI 工作流配置。
- 模型调用、审计和安全策略。

## 3. 研发闭环

标准闭环如下：

1. 需求澄清：明确业务目标、边界、非功能要求和验收标准。
2. 上下文收集：读取项目结构、规范、依赖、公共组件和相关模块。
3. Prompt 设计：按照 Prompt Spec 编写或复用 Prompt。
4. 方案设计：输出架构方案、风险点、接口设计和测试策略。
5. 代码实现：按 DDD、RESTful、安全、测试规范实现。
6. 自动化验证：执行单测、集成测试、静态检查和必要的安全检查。
7. AI Review：覆盖架构、安全、性能、事务、缓存、SQL、并发和可测试性。
8. 人工 Review：对高风险变更、数据库变更、权限变更和公共协议变更进行确认。
9. 发布与观测：上线后关注日志、指标、链路追踪和告警。
10. 复盘沉淀：沉淀 Prompt、评测样例、问题模式和最佳实践。

## 4. 角色与职责

| 角色 | 职责 |
| --- | --- |
| Product Owner | 明确业务目标、范围和验收标准。 |
| Architect | 维护架构边界、模块依赖和关键技术决策。 |
| Developer | 实现生产级代码、测试和文档。 |
| AI Agent | 辅助分析、生成、Review、评测和文档沉淀。 |
| Reviewer | 审核代码质量、安全风险和业务正确性。 |
| Platform Owner | 维护 AI 网关、Prompt 仓库、评测平台和治理策略。 |

## 5. 质量门禁

每次变更必须通过以下门禁：

- 需求范围清晰。
- DDD 分层未被破坏。
- API 符合 RESTful 与统一响应规范。
- 数据库访问无 `SELECT *`、N+1、循环 SQL 和明显索引风险。
- 日志不包含敏感信息。
- 安全要求已覆盖鉴权、越权、注入、防重复提交和审计。
- 单元测试和必要集成测试通过。
- 文档、Prompt 或工作流变更已同步更新。

## 6. 风险分级

| 等级 | 定义 | 处理要求 |
| --- | --- | --- |
| Blocker | 会导致系统不可用、数据泄露、资金或权限严重风险。 | 必须立即阻断合并。 |
| Critical | 影响核心业务正确性、安全或数据一致性。 | 修复后重新 Review。 |
| Major | 影响可维护性、性能、扩展性或测试稳定性。 | 合并前必须有明确处理方案。 |
| Minor | 局部代码风格、命名或文档问题。 | 可在当前或后续迭代修复。 |
| Suggestion | 优化建议，不影响当前交付。 | 团队评估是否采纳。 |

## 7. 关键资产管理

### 7.1 AGENTS.md

`AGENTS.md` 是 AI 执行任务时必须遵守的工程宪法，维护项目级研发规范、架构边界和行为约束。

### 7.2 Prompt Spec

`prompts/PROMPT_SPEC.md` 是 Prompt 资产的设计、版本、评测和发布标准。

### 7.3 Workflows

`workflows/` 维护需求分析、开发、Review、评测、发布、回滚等流程。

### 7.4 Evaluation Center

`evaluation-center/` 用于沉淀 AI 生成质量、Prompt 效果、Review 命中率和回归评测资产。

## 8. 度量指标

建议持续度量：

- AI 生成代码一次通过率。
- AI Review 问题命中率。
- Prompt 版本质量趋势。
- 单元测试覆盖率。
- 缺陷逃逸率。
- 安全问题数量。
- 平均交付周期。
- 返工率。

## 9. 变更治理

以下变更必须升级评审：

- 数据库结构变更。
- 公共 API 协议变更。
- 鉴权、权限、审计相关变更。
- 支付、资金、隐私和敏感数据相关变更。
- AI 网关模型路由、限流、审计策略变更。
- 核心基础设施和公共组件变更。

## 10. 下一阶段建设重点

下一阶段优先建设 `user-center` 模块，并同步完善：

- 用户领域模型。
- 用户注册、登录、权限与审计用例。
- 统一 API、DTO、VO、错误码和测试样例。
- 与 AI Review、Prompt 评测、研发工作流的集成样板。
